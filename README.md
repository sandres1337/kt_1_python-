# kt_1_python-

скачайте и откройте проект в VSC
установите следующие библиотеки прописав следующие команды в терминале:

pip install fastapi uvicorn (для разработки, а так же что бы код сам перезапускался, когда обновляем файлы)
pip install dotenv (для работы с env, там будет localhost)

после установки библиотек нужно запустить проект командой:
python main.py
